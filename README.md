# 我和三毛的一天

线上地址：<https://zhangssyy.github.io/One-Day-with-Sanmao/>

项目是一套「衡复街区实体沙盘 × 手机 AR」的叙事体验：游客用手机对着街区沙盘，陪三毛走过一天的四个时段，把沿途的共同经历收进一本四格绘本。

| 时段 | 环节 | 地点 |
| --- | --- | --- |
| 08:00—11:00 | 唤醒三毛 | 张乐平故居 |
| 11:00—14:00 | 重现四格漫画 | 良友公寓 / 上影小白楼（两条支线任选其一） |
| 14:00—17:00 | 遇见柯灵 | 柯灵故居 203 室 |
| 17:00—20:00 | 义卖和策展 | 中国福利会 · 宋庆龄文化空间 |

第一站的最后一环是「三毛带你进入一层虚拟展厅」。**这个网页就是那一环的原型**：先不依赖沙盘和 AR 设备，把张乐平旧居的空间漫游与作品阅读在浏览器里完整跑通，用于课堂演示和内容校核。

第三站的最后一环「抽书签」也在本仓库：**[柯灵书签](https://zhangssyy.github.io/One-Day-with-Sanmao/keling/)**，源码在 `keling/`。晃一晃手机（或点按钮），从 150 条核对过出处的柯灵文字里抽一枚竖排书签；每台手机限抽一枚，抽中后整屏是一张带项目信息和二维码的海报，方便截图转发。

其余环节（AR 识别与沙盘配准、笔墨砚收集、手指描画、两条午间支线、柯灵故居交互的其余部分、义卖与挂画）仍在筹备，设计方案与史料研究见组内资料，未纳入本仓库。


## 素材来源

上海交通大学人居设计专题《虚实融合空间设计：城市遗产数智再生》张乐平柯灵单元课程作业，非商业用途。

- **空间影像**：上海「建筑可阅读」张乐平故居 VR（<https://wtscvr.xh.sh.cn/>）的本地镜像，保留 12 个实拍全景位置。
- **漫画作品**：三毛官方网站（<https://www.sanmao.com.cn/>）。作品著作权属张乐平先生及其继承人。
- **柯灵文字**：每条签文都保留篇名、年份与出处链接（见 `keling/quotes.js`）。书签页的签筒、贴纸、故居构件线稿等插图由图像生成模型绘制，故居构件依据柯灵故居（复兴西路 147 号）实景转译。正文字体为 [Noto Serif SC](https://github.com/notofonts/noto-cjk)（SIL Open Font License）按签文用字裁出的子集。
- **线上策展**：墙面作品的点击位置依据实景与官网图像比对配置；每件作品的原始页面地址记录在 `sources.json` 中。
